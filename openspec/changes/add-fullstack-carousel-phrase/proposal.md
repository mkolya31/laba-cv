# Proposal

## Why

Автор хочет дополнить карусель фразой «Умею в фронт, бэк и devops», чтобы показать широту своих навыков. Формулировка предоставлена самим автором.

## What Changes

- Добавить точную фразу «Умею в фронт, бэк и devops» третьей, сразу после «лучший разработчик Сбера 2023» и перед «люблю вайбкодить».
- Сохранить пять существующих фраз, начальный экран и поведение переключателя.
- Учесть новый набор из шести фраз в проверках полного цикла, клавиатурной навигации и адаптивности.
- Вне объёма: переработка карусели, изменение регистра текста, новые зависимости и изменение деплоя.

## Capabilities

### New Capabilities

- `profile-presentation`: дополнение набора фраз карусели точной авторской формулировкой. В основных спецификациях capability пока отсутствует; тот же путь уже используется незавершённым `build-resume-mvp`. Новый delta добавляет отдельное требование и не переопределяет его требования.

### Modified Capabilities

Нет.

## Impact

Затронуты массив `phrases` в `src/content/profile.ts` и проверки в `tests/site.spec.ts`. Компонент `src/components/PhraseSwitcher.tsx` уже использует длину массива для переходов, индикаторов и резерва места.

Существующий стек: Next.js, React, TypeScript. Целевое позиционирование MVP — разработчик для R&D-команды лаборатории кибербезопасности Сбера, создающей агента проверки ПО; формального текста вакансии нет. Объём MVP расширяется только одной фразой. При последующей синхронизации необходимо сохранить требования `profile-presentation` из обоих изменений.
