# Proposal

## Why

В [issue #8](https://github.com/mkolya31/laba-cv/issues/8) автор просит убрать с фотографии фразу «Идея → прототип → продукт»: она не добавляет смысла к остальным элементам страницы. Удаление упростит первый экран сайта.

## What Changes

- Убрать текст «Идея → прототип → продукт» из подписи поверх портрета, без замены другой фразой и без скрытой копии в разметке.
- Сохранить соседнюю подпись «01 / Знакомство», фотографию, альтернативный текст и адаптивную композицию первого экрана.
- Объём этой итерации MVP — одно визуальное упрощение существующей русскоязычной страницы. Вне объёма: замена фотографии, редизайн, изменение карусели, кейсов, контактов и механизма публикации.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `profile-presentation`: закрепить отсутствие указанного слогана поверх фотографии при сохранении подписи раздела и доступного портрета.

## Impact

Изменение затрагивает разметку `src/app/page.tsx`. Стили `.portrait-caption` в `src/app/globals.css` уже допускают один оставшийся элемент; необходимость корректировки проверяется визуально. Новые зависимости и изменения изображения `public/portrait.webp` не требуются.

Существующий стек: Next.js App Router, React, TypeScript, статический экспорт для nginx на Ubuntu VPS с GitHub Actions. Целевое позиционирование из предложения MVP: фронтенд-разработчик для R&D-команды лаборатории кибербезопасности Сбера, создающей агента проверки ПО; формального текста вакансии нет. Проверки опираются на существующий Playwright-набор и production-preview.
