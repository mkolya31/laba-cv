# Spec Delta

## ADDED Requirements

### Requirement: Ссылка на доказательства опыта

Первый экран SHALL показывать ссылку «Посмотреть доказательства» со стрелкой вниз, ведущую к разделу кейсов `#cases`. Прежняя подпись «Посмотреть, что я сделал» SHALL отсутствовать в первом экране. Ссылка SHALL сохранять текущее оформление, видимый фокус и работоспособность без JavaScript.

#### Scenario: Подпись и переход к кейсам

- **WHEN** посетитель открывает главную страницу
- **THEN** в первом экране видна ссылка с точным текстом «Посмотреть доказательства» и стрелкой вниз
- **AND** прежняя подпись отсутствует
- **WHEN** посетитель нажимает ссылку
- **THEN** происходит переход к разделу кейсов на этой же странице

#### Scenario: Активация с клавиатуры

- **WHEN** посетитель переводит фокус на ссылку клавишей Tab
- **THEN** фокус ссылки виден
- **WHEN** посетитель нажимает Enter
- **THEN** происходит переход к разделу кейсов

#### Scenario: Работа без JavaScript

- **WHEN** посетитель открывает страницу с отключённым JavaScript и активирует ссылку «Посмотреть доказательства»
- **THEN** новая подпись и стрелка видны, а переход к разделу кейсов работает

#### Scenario: Читаемость на разных экранах

- **WHEN** посетитель просматривает страницу при ширинах 360, 768 и 1440 CSS-пикселей или увеличивает текст до 200% на узком экране
- **THEN** подпись ссылки читается полностью, без обрезки, перекрытия и горизонтальной прокрутки страницы
