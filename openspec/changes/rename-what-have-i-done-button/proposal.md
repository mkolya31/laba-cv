# Proposal

## Why

В задаче [#23](https://github.com/mkolya31/laba-cv/issues/23) автор попросил заменить подпись «Посмотреть, что я сделал» на «Посмотреть доказательства». Новая формулировка приглашает посетителя проверить заявленный опыт через кейсы.

## What Changes

- Заменить текст ссылки первого экрана на точный текст «Посмотреть доказательства».
- Сохранить якорь `#cases`, стрелку вниз, оформление и доступность ссылки с клавиатуры и без JavaScript.
- Зафиксировать новую подпись и сохранение перехода в требованиях `profile-presentation`.
- Вне объёма: переименование раздела кейсов, редактирование достижений, изменение карусели, стилей, стека и механизма публикации.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `profile-presentation`: добавить требование к подписи ссылки первого экрана, ведущей к кейсам.

## Impact

Изменение ограничено текстом ссылки `.hero-copy .text-link` в `src/app/page.tsx`. Используется текущий стек Next.js App Router, React и TypeScript со статическим экспортом для nginx на Ubuntu; зависимости и API не меняются. Проверки выполняются существующими средствами проекта и ручным просмотром ссылки, без отдельного набора тестов для замены строки.

Сайт ориентирован на работу в R&D; архивное предложение описывает позиционирование для R&D Сбера, формального текста вакансии нет. Это точечное изменение существующего MVP и не требует выбора новой вакансии или стека. Новые сведения об опыте не добавляются. Публикация остаётся в существующем процессе GitHub Actions.
