## Настройки GitHub через браузер

16 ноября 2026 года подтверждена действующая браузерная сессия владельца репозитория. Ветка `production` уже существовала к началу этого этапа.

- Создано classic branch protection rule для `production`: обязательный PR без требования отдельного ревьюера, обязательный `verify` от GitHub Actions, актуальность PR, запрет обхода администраторами. Force push и удаление не разрешены. GitHub подтвердил сохранение правила.
- Для Environment `production` выбраны Selected branches and tags и единственное правило типа Branch с точным именем `production`. GitHub подтвердил: 1 branch and 0 tags allowed. Environment secrets пока отсутствуют.
- `production-source` пока нельзя выбрать как required check: новый workflow ещё не опубликован и check отсутствует в списке репозитория. Задача 6.12 остаётся незавершённой до добавления этого check и проверки запретов.
- Прямой SSH-доступ Git к GitHub не прошёл проверку publickey; HTTPS dry-run также сообщил о недействительных сохранённых учётных данных. Начат отдельный стандартный браузерный вход GitHub CLI; секреты и одноразовые коды в этот документ не записываются.

Браузерная авторизация GitHub CLI завершена, вход под владельцем подтверждён. Старые сообщения 401 выше описывают состояние до восстановления доступа. Публикация нового workflow и добавление production-source выполняются следующим шагом.
