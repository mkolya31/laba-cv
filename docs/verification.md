# Локальная проверка

Проверено 15 ноября 2026 года на Windows, Node.js 24.14.1, браузер Microsoft Edge через Playwright.

- Чистая установка `npm ci` выполнена.
- Production-экспорт Next.js собирается, TypeScript проходит.
- Браузерные smoke-проверки: кейсы до резюме, два способа связи из фиктивного JSON, внешний PDF и ошибка загрузки конфигурации, новая вкладка, шестисекундная смена фраз, ручной выбор и ожидание 30 секунд, сохранение остановки при фокусе, сокращённое движение.
- Ширины 360/768/1440 px: все фразы перебраны без смещения следующего раздела и горизонтальной прокрутки.
- Удвоенный размер текста на 360 px и чтение без JavaScript проверены автоматически.
- Снимки production-страницы на 1440 и 360 px просмотрены: декоративные полосы и смешивание поверх портрета удалены, лицо видно полностью.
- Генератор проверен на фиктивных данных: default /resume.pdf, внешний HTTPS-адрес, отклонение небезопасной ссылки, сохранение прежнего JSON при ошибке и отсутствие посторонних переменных в выводе.
- Переданный PDF проверен чтением pypdf: 3 страницы; файл не скопирован в проект. Срок SberUnity уточнён автором: 3 месяца от идеи до прототипа.

## Требует проверки на VPS

Домен и серверный доступ пока не предоставлены. Не проверены реальные HTTPS/DNS/сертификат, контакты, открытие выбранного PDF по публичному адресу, соседние сайты, права пользователя доставки, фактический запуск GitHub Actions, передача сборки, переключение и откат релиза на Linux. Публичная доступность GitHub-репозитория отдельно не подтверждена. Соответствующие задачи OpenSpec не считаются завершёнными.

Скрипты, workflow и nginx-конфигурация подготовлены; их наличие не заменяет проверки опубликованного сайта.
